## 🚀 What Is This?

**affinity-photo-new** is a free, powerful bridge that connects Google's artificial intelligence (Gemini) directly to your Serif Affinity apps—**Affinity Photo**, **Affinity Designer**, and **Affinity Publisher**. With this tool, you can generate vector graphics, automate canvas tasks, and create designs programmatically—all without writing a single line of code.

Think of it as your personal AI design assistant that works right inside your favorite Affinity software.

## 💡 Tips for Best Results

### 🗣️ Speak Naturally
Don't worry about technical terms. Simply describe what you want:
- Instead of: "Create path with bezier curves"
- Try: "Draw a wavy line across the top"

### 🧪 Start Simple
Begin with basic commands before trying complex operations. A good starting point:
- "Make a blue circle"
- "Duplicate the selected layer"
- "Align all layers to center"

### 📚 Keep the Terminal Open

**No!** Everything is controlled through simple English commands. If you can chat, you can use this tool.

## 🔧 Troubleshooting

### 😕 The AI panel doesn't appear
- Make sure you've run the application first (`affinity-photo-new.exe`)
- Restart your Affinity app after starting the tool
- Check that your firewall isn't blocking the connection

### ⚠️ Connection error
- Ensure the command prompt window is still open
- Try running the tool **as Administrator** (right-click → "Run as administrator")
- Close other programs that might interfere

### 🐢 It's running slowly
- Close unused browser tabs and applications
- Make sure you're on a stable internet connection
- Restart both the tool and Affinity

### ❌ App doesn't start
- Right-click the `.exe` file and select **"Troubleshoot compatibility"**
- Make sure you've extracted ALL files (not just the executable)
- Temporarily disable antivirus software during first run
